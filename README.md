# Navatar

*Navatar* is a video conferencing **"avatar"** on wheels that allows doctors to remotely visit patients and talk to them in real time.

It is split into multiple repositories, each handling a different part of the system:

---

## 📂 Project Repositories

### 🔹 [Navatar User Frontend](https://github.com/Suja2004/Navatar-User-Frontend)  
The frontend of Navatar, built with modern web technologies to provide users with an intuitive and responsive interface.

---

### 🔹 [Navatar Backend](https://github.com/Suja2004/Navtar)  
The backend system that powers Navatar.  
It manages data storage, authentication, and communication between different services.

---

### 🔹 [Navatar Interface](https://github.com/Suja2004/Navatar-Interface)  
The interface layer of Navatar that connects the backend and frontend, ensuring smooth data flow and efficient system integration.

---

### 🔹 [WebRTC Consultation](https://github.com/Suja2004/WebRTC)  
A WebRTC-based real-time communication module integrated into Navatar for consultation features such as video/audio calling and live assistance.
